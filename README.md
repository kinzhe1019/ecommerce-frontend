# E-commerce Full Stack - Frontend

Proyecto de tienda online del módulo Desenvolupament d'aplicacions amb Frameworks client/servidor(curs 2026-2027).
Este repositorio contiene el Frontend.

## Tecnologías

- React
- Node.js / Express
- MongoDB
- Docker

## Autor
Xinkai Zheng

## Cómo ejecutar el proyecto

1. Clonar el repositorio: git clone https://github.com/kinzhe1019/ecommerce-frontend.git
2. Entrar en la carpeta: cd ecommerce-frontend
3. Instalar dependencias: npm install
4. Arrancar el proyecto: npm start
